# مفقوداتي الجامعية 🎒 
منصة إلكترونية تهدف إلى تسهيل عملية العثور على المفقودات داخل الحرم الجامعي، من خلال ربط الطلاب الذين فقدوا أغراضهم بالطلاب الذين عثروا على أغراض مفقودة.

تتيح المنصة لكل طالب فقد شيئاً أن ينشر إعلاناً يوضح فيه تفاصيل الغرض المفقود، مثل اسمه ووصفه ومكان وتاريخ فقدانه، كما تتيح للطلاب الذين عثروا على أغراض مفقودة نشر إعلانات تتضمن تفاصيل الأشياء التي وجدوها.

تساعد هذه الإعلانات على نشر المعلومات بين طلاب الجامعة، مما يزيد من فرص وصول الغرض المفقود إلى صاحبه الحقيقي، ويساهم في توفير الوقت والجهد وتقليل مشكلة ضياع الممتلكات الشخصية داخل الجامعة.
## المرحلة الأولى: HTML + CSS + JavaScript
في هذه المرحلة لا يوجد خادم ولا PHP. كل الوظائف تعمل داخل المتصفح بـ JavaScript، والبيانات تُحفظ في `localStorage`.
في المرحلة الثانية سيُضاف PHP ويُرفع الموقع على InfinityFree.

## التقنيات
- HTML5
- CSS3 و Bootstrap 5 (RTL) وخطوط ثمانية
- JavaScript (localStorage، FormData، FileReader، Canvas)

## الصفحات
| الصفحة | الوصف |
|---|---|
| `index.html` | الرئيسية (واجهة للزائر وواجهة للمستخدم) |
| `login.html` | تسجيل الدخول |
| `register.html` | إنشاء حساب مع اختيار الكلية |
| `items.html` | عرض الأغراض مع بحث وفلترة فورية |
| `add-item.html` | إضافة غرض مع معاينة الصورة |
| `returned.html` | الأغراض التي تم تسليمها لأصحابها |
| `contact.html` | تواصل معنا |

## ملفات JavaScript
- `assets/auth.js`: يعرف هل المستخدم مسجّل، ويحمي الصفحات الخاصة.
- `assets/script.js`: التسجيل والدخول، إضافة الأغراض، البحث، زر «تم التسليم لصاحبه»، رسائل التواصل.

## طريقة التشغيل
افتح `index.html` في المتصفح. لا يحتاج أي إعداد.
